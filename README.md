# 微信电商商城小程序

一个完整的电商商城微信小程序项目。

## 功能特性

- 🏠 **首页展示**: 轮播图、商品列表展示
- 📦 **商品分类**: 左右分栏分类浏览
- 🛒 **购物车**: 商品管理、数量调整、价格计算
- 👤 **用户中心**: 用户信息、订单管理、地址管理
- 📱 **商品详情**: 图片轮播、商品信息、加入购物车、立即购买

## 技术栈

- 微信小程序原生开发
- 微信小程序 API
- 微信小程序组件

## 项目结构

```
wechat-miniprogram-mall/
├── pages/              # 页面目录
│   ├── index/          # 首页
│   ├── category/       # 分类页
│   ├── cart/           # 购物车
│   ├── user/           # 用户中心
│   └── detail/         # 商品详情
├── images/             # 图片资源
├── utils/              # 工具函数
├── app.js              # 小程序入口
├── app.json            # 小程序配置
├── app.wxss            # 全局样式
└── project.config.json # 项目配置
```

## 快速开始

### 1. 下载项目

```bash
git clone git@github.com:Haojie-Zhou/wechat-miniprogram-mall.git
```

### 2. 打开微信开发者工具

1. 打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目，选择项目目录
3. 填写 AppID（测试可用测试号）
4. 点击"导入"

### 3. 运行项目

导入成功后，项目会自动编译运行

## 开发说明

### 页面说明

- **index**: 首页，展示轮播图和热门商品
- **category**: 商品分类页，左右分栏展示
- **cart**: 购物车页面，管理购物车商品
- **user**: 用户中心，展示用户信息和订单状态
- **detail**: 商品详情页，展示商品详细信息

### 数据说明

当前项目使用模拟数据，实际开发中需要对接后端 API。

需要对接的主要接口：
- 商品列表接口
- 商品详情接口
- 购物车接口
- 用户登录接口
- 订单相关接口
